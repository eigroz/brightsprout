# Spell Quest under BrightSprout

GitHub source: https://github.com/eigroz/brightsprout/tree/main/games/spell-quest

Cloudflare hub: https://brightsprout-cp4.pages.dev/

Game: https://brightsprout-cp4.pages.dev/games/spell-quest/

Cloudflare Pages project `brightsprout` deploys automatically from this repository's `main` branch. No build command; output directory `.`; repository root.

The README and production plan in this folder are the original standalone project notes. In this repository, `site/` in those notes means `games/spell-quest/`.

The game currently stores child profiles and results in local browser storage. Hosting the code does not back up player records. Existing progress on the GitHub Pages demo remains on that origin and does not automatically transfer here. Cloud accounts are not enabled.

The confidence tracker is an initial rule-based view of first-attempt results, with suggested word categories; it is not a validated diagnostic assessment. Further work is needed on error-specific analysis, delayed recall checks and teaching content review.
